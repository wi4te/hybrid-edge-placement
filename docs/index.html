How It Works
🧬
Genetic Algorithm
Evolves a population of server assignments over 40 generations. Chromosome = list of server IDs per service. Optimizes for privacy (minimum data spread).
🌊
Particle Swarm Optimization
40 particles explore continuous position space, discretized to server IDs. Cognitive + social forces converge to global best. Optimizes for latency.
🤖
Multi-Agent RL + GAT
One DQN agent per region. Graph Attention Network encodes server topology. Curriculum learning: 1→8 service complexity. Optimizes for load balance.
⚡
Hybrid Engine
Routes each request to the best-suited algorithm based on app type, deadline, and current load. Falls back to alternative if primary fails. Best overall performance.
